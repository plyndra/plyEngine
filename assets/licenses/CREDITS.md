# Credits and licences

Almost nothing should be here. plyEngine's art is generated self-hosted and owned
by the project (`docs/planning/ART_PIPELINE.md`), so the default entry count is
zero.

This file exists for two narrow cases:

1. **Attributed reference material used as a test fixture** (CC BY). Fixtures may
   live under `tests/data/art/` with their licence files; the credit line is
   still required because this repository is public even though release archives
   never include them.
2. **A recorded fallback decision** if a hosted generator is used for an asset
   class (see `ART_PIPELINE.md` §8a), in which case its terms are recorded next
   to the asset's provenance.

| Asset / pack | Author | Licence | Where used | Obligation |
|---|---|---|---|---|
| _(none yet)_ | | | | |

## Licence files

Every downloaded pack's licence text is stored verbatim at
`assets/licenses/<pack>.txt`, alongside the source URL and the sha256 of the
downloaded archive. "We think it was CC0" is not a licence record.
