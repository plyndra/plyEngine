## Defect found by doing the work (C0.6 grader)

Launching any demo without flags ran `app.runFrames(frames > 0 ? frames : N)`,
so **every demo exited in ~0.4 s**. `./ply_companion` printed a room code and
died — the flagship "open the URL on your phones" path was unusable in v1.0.0.
Fixed: `app.run()` is the no-flag default across all six demos; `--frames`,
`--verify`, `--screenshot`, `--dump-frames` keep the bounded behaviour. CI gained
a step that requires each demo to still be alive after 4 s with no flags.

Second defect: `PLY_VERSION_STRING` is a cache variable, so reconfiguring an
existing build tree keeps the old value and the runtime banner lies. Not
release-affecting (CI configures fresh and asserts `kVersion`), but it is why a
local binary reported `1.0.0-beta.2` while `CMakeLists.txt` said `1.0.1`.

Both recorded in `promotion.log`; the fix is `1.0.1` in `CHANGELOG.md`.
